# GOUROB X CHEAT — Store

Static store (HTML + Firebase). No build step.

## Run with GitHub Pages
1. GitHub repo → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** → Save
3. Site URL: `https://swampodsarkar321.github.io/GOUROB-X-CHEAT-/`

## Firebase setup
1. Authentication → Email/Password → Enable, add users
2. Realtime Database → Rules → paste `database.rules.json` → Publish
3. Storage rules only needed if uploading files (images use imgbb)
